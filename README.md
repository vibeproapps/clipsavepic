# ClipSavePic

Программа для области уведомлений Windows: сохраняет изображения, скопированные
в буфер обмена (скриншоты, «Копировать картинку» в браузере, Paint и т.п.),
в файлы PNG, JPEG, GIF или BMP. Без внешних зависимостей — только стандартная
библиотека Go и Win32 API.

## Сборка

```bash
go build -ldflags "-H windowsgui" -o clipsavepic.exe .
```

Флаг `-H windowsgui` убирает окно консоли.

## Использование

После запуска в трее появляется значок: **серый** — автосохранение выключено
(так по умолчанию), **зелёный** — включено. Двойной щелчок переключает режим,
правый щелчок открывает меню:

- **Автосохранение** — вкл/выкл (то же, что двойной щелчок). Если папка ещё
  не выбрана, сначала откроется выбор папки.
- **Папка автосохранения: …** — выбрать папку.
- **Формат сохранения ►** — PNG / JPEG / GIF / BMP и качество JPEG
  (100, 95, 90, 80, 70, 50%; по умолчанию 90%).
- **Открыть папку в проводнике**.
- **Сохранить как…** — сохранить текущее изображение из буфера в любой файл;
  формат определяется по расширению (тип файла по умолчанию — выбранный формат).
- **Сохранить** — однократно сохранить текущее изображение в папку автосохранения.
- **Автоматически запускать при запуске системы**.
- **О программе…**, **Выход**.

Особенности форматов:

- **PNG** — без потерь, с прозрачностью. Если источник положил в буфер готовый
  PNG, он записывается как есть.
- **JPEG** — прозрачные области заливаются белым.
- **GIF** — не больше 256 цветов: при большем числе цветов палитра подбирается
  автоматически с диффузией ошибки; полупрозрачное становится либо прозрачным,
  либо непрозрачным.
- **BMP** — без сжатия; при наличии прозрачности пишется 32-битный BMP с альфа-каналом.

Картинки, скопированные вместе с текстом (ячейки Excel, фрагменты Word),
автоматически не сохраняются; запустите с флагом `-text`, чтобы сохранять и их.
Одно и то же изображение, скопированное повторно подряд, второй раз не сохраняется.
После каждого сохранения (автоматического и ручного) показывается уведомление
с именем файла.

Файлы называются `clip_ГГГГ-ММ-ДД_чч-мм-сс_мс.<расширение>`.

## Флаги командной строки

| Флаг    | Описание |
|---------|----------|
| `-text` | автосохранять картинки, скопированные вместе с текстом |
| `-log`  | писать журнал в указанный файл |

## Где хранятся настройки

`HKCU\Software\GoSavePic`: `Folder` (папка), `Format`, `JpegQuality`.
Автозапуск — значение `GoSavePic` в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
Состояние автосохранения не запоминается: при каждом запуске оно выключено.
